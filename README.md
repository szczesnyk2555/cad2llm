# cad2llm

Upload a CAD file (**STEP/STP** or **DXF**), get its measurements extracted locally and a description of the part from an OpenAI model.

OpenAI does not accept `.step` / `.dxf` files, and raw CAD text is huge and hard for a model to measure from. So the file is pre-processed locally into a compact JSON with exact measurements plus a preview PNG, and only that is sent (Responses API, `store: false`).

| Format | Extracted (cadquery / ezdxf) | Preview |
|---|---|---|
| STEP / STP | declared units (geometry normalized to mm), bounding box, volume, surface area, face/edge counts, cylinder diameters with counts, per-solid values for assemblies | isometric shaded view |
| DXF | units (`$INSUNITS`), extents, DIMENSION values + text overrides, circle diameters, arc radii, line and polyline segment lengths, TEXT/MTEXT, layers; geometry inside blocks included | 2D drawing |

All floats are rounded to 3 decimals.

## Install

Python 3.11+.

```bash
python -m venv .venv
.venv\Scripts\activate          # Linux/macOS: source .venv/bin/activate
pip install -e ".[test]"
copy .env.example .env          # then put your key in .env
```

`.env`:

```
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-6-astra        # any vision-capable model
```

## Web app

```bash
python -m cad2llm.web           # http://127.0.0.1:8000  (HOST / PORT env vars to change)
```

Choose a file, optionally ask a question, click **Analizuj**. The page shows the model's description, the preview and the exact JSON that was sent. Tick *tylko pomiary* to skip the API call.

## CLI

```bash
python -m cad2llm samples/flange.step --dry-run          # print extracted JSON, no API call
python -m cad2llm samples/plate.dxf                      # description from the model
python -m cad2llm part.step --prompt "Jak to wykonać na tokarce?" --no-image
```

## Samples and tests

`samples/flange.step` and `samples/plate.dxf` are generated by `python samples/make_samples.py`. `pytest` runs the extractors on them (no API calls).

## Limitations

- **DWG is not supported**: save / export it as DXF (or STEP for 3D) first.
- STEP: only B-rep geometry is measured; PMI (tolerances, notes) and materials in the file are not read. Diameters come from cylindrical faces only (cones, tori and splines are not listed).
- DXF: model space only (paper space layouts are not read); polyline arcs (bulges) are measured as chords; hatches are ignored.
- The model's description is only as good as the extracted data and the preview. Check the numbers against the JSON.
